User 核銷

此功能會先向雲端確認核銷服務是否就緒；僅接受實體紙本正本，測試券與重複核銷均由伺服器拒絕。

正式核銷規則

獎券由 B3S 印表機列印含唯一 QR Code 的實體紙本正本；正式核銷需取得完整 QR Code 內容；單獨輸入兌換編號不能核銷。未來由伺服器驗證獎券來源、有效期限及核銷狀態，每張獎券限兌換一次，過期或已核銷不得再次使用。

可使用手機相機讀取紙本 QR，或貼入掃描到的完整內容；伺服器依實際登入權限、獎券狀態及有效期限判定是否可核銷。
