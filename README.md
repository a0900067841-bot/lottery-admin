# 電子抽獎機管理網站 v0.1.2

GitHub Pages 靜態測試版，四個檔案直接上傳儲存庫根目錄即可。

本版修改：
- 「有效天數」介面名稱改為「序號有效期限（天數）」
- 「兌換編號」統一改為「活動序號」
- 原本「使用方式」欄位改為「活動說明」，放在使用規則前
- 列印日期與時間同一行，位於 QR Code 正上方
- QR Code 下方顯示活動序號及序號有效期限
- 保留原版獎券視覺風格，活動說明／使用規則／注意事項分段
- 保留原本 localStorage 儲存鍵，升級不主動清除資料

注意：若瀏覽器先前儲存了自訂模板，升級後仍顯示原有規則與說明，請在「獎券設定」自行修改。此版沒有正式 QR、後端資料庫、真實核銷或 B3S 列印。
