# 電子抽獎機管理平台 v0.1.4（靜態展示版）

## v0.1.4 修正
- 移除舊版自動填入的「示範門市」；舊資料如仍是該預設名稱，第一次開啟新版會自動清除一次。其他自訂店名不變。
- 門市名稱欄位留空，獎券最上方直接顯示獎項名稱，不會保留空白。
- 修改門市名稱或獎券設定時，預覽即時更新；按「儲存模板」才會保存。
- 保留原本獎項管理、設定、測試核銷展示功能。

## 本版更新
- 獎券預覽依 55 mm 紙寬排版，保留左右各 2 mm 安全邊界。
- 門市名稱為選填；留空時不顯示，也不保留空白標題。
- 獎項名稱置中，列印日期、活動序號、序號有效期限靠左。
- QR Code 為明確標示的佔位圖，**不是可掃描或可核銷的正式 QR Code**。
- 活動序號在展示版固定顯示 DEMO-NOT-VALID，不提供編輯欄位。正式版必須由伺服器產生唯一序號並保存。
- 活動說明、使用說明、注意事項沿用原本可編輯設定。
- 紙張模式預定連續紙／小票紙 3；55 mm 是實際紙捲寬度，尚未實測 B3S 有效列印寬度。

## 部署
將 ZIP 內四個檔案解壓後，放在 GitHub Pages 儲存庫根目錄，覆蓋同名檔案。

## 注意
這是 localStorage 的 UI 展示版，無後端、無正式登入、無實際抽獎、無真實 QR 核銷、無 B3S BLE 列印。切勿將示意序號視為有效獎券。
