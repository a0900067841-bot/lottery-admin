# 電子抽獎機管理平台 v0.1.0

## 使用方式
將 `index.html`、`style.css`、`app.js` 一起上傳至 GitHub 儲存庫根目錄，啟用 GitHub Pages（Settings → Pages → Deploy from a branch → main / root）。網站可於手機瀏覽器使用。

## 已包含
- 管理總覽
- 測試獎項新增、修改、刪除及權重
- 店名、有效天數、使用方式、九條規則及注意事項編輯
- 紙本獎券版面示意預覽
- User 手動輸入核銷介面（不可實際核銷）
- 瀏覽器 localStorage 本機儲存

## 重要限制
這是 **無後端的介面展示版**。沒有正式登入與權限驗證、沒有真正的 QR Code、沒有真實獎券、沒有雲端資料庫、沒有 ESP32 / B3S 連線、沒有可用的核銷功能。Admin/User 分頁並非安全隔離。請勿用於真實顧客抽獎、發券或兌換。

正式版需新增伺服器端抽獎與唯一識別碼生成、資料庫交易、登入權限、不可重複核銷、店別與期限驗證、ESP32 裝置驗證、B3S 實測列印排版。核銷必須查驗實體紙本正本，不受理截圖或影本。
