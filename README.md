# 電子抽獎機 Admin v0.1.7（展示／整合準備版）

## 操作流程
1. Admin 在獎券設定調整紙寬、條碼、字級、內容、期限與顯示開關。
2. 同一個表單下方即時預覽；不必先儲存。
3. 按「儲存為列印模板」，才把當前設定存到此瀏覽器的 localStorage（沿用既有 KEY，不清除先前資料）。
4. 未儲存變更不會取代已儲存模板；可按「放棄修改，還原已儲存設定」。
5. 列印前置狀態顯示已儲存的紙寬、條碼、期限及尺寸。可匯出已儲存模板 JSON，供日後 ESP32 設定同步介面開發。

## 尚未完成
- 這是 GitHub Pages 靜態展示版：沒有後端登入、雲端資料庫、ESP32 連線或 B3S 直接列印。
- 儲存僅代表本機模板已確定，**不代表 ESP32 已收到設定，也不代表現在能按鍵印正式券**。
- QR／Code 128 都是不可掃描的版面示意；正式發券需伺服器生成唯一序號，並安全記錄與驗證。
- 正式核銷必須持原店紙本正本；照片、截圖、影本、電子圖片均不受理。
- 既有 v0.1.6 的獎項、模板、蜂鳴器偏好仍保留；沒有更改 ESP32 V05 韌體。
