# 電子抽獎機管理網站 v0.1.1

靜態展示版。獎項管理新增「總數量」，清單顯示「總數量／已抽出／剩餘」。目前沒有正式抽獎功能，已抽出數量不會增加，也不會扣除庫存。正式庫存扣減必須由後端交易處理。

## 手機上傳 GitHub

解壓縮 ZIP，將內部四個檔案 `index.html`、`app.js`、`style.css`、`README.md` 上傳至 `lottery-admin` 儲存庫根目錄，覆蓋同名檔案。不要上傳外層資料夾或 ZIP。

沿用 v0.1.0 的本機儲存資料，既有獎項因舊版沒有數量欄位，會先顯示 0；請進入編輯設定數量。

此版本不具備真實登入、資料庫、ESP32/B3S 列印及核銷功能。
