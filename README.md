# 電子抽獎機 Admin v0.1.8｜設備設定匯出與備份還原

沿用 v0.1.7 網頁介面及既有 localStorage keys，不主動清除原資料。

## 新增功能
- 在「獎券設定 → 列印前置狀態」下載完整設備設定 JSON（`lottery-device-config-v1.json`），包括**已儲存**獎券模板、獎項、蜂鳴器偏好。
- 匯入相同格式的 JSON，先檢查 schema/version、字串長度、數值範圍、獎項庫存與提示音，再二次確認，才覆蓋目前瀏覽器資料。
- 保留舊版「只匯出獎券模板」JSON 按鈕，避免破壞既有流程。
- 明確顯示「設定檔已匯出」與「設備已同步」是兩回事。

## 目前邊界
- 尚未連接 ESP32，**下載或匯入 JSON 不會控制 B3S 列印**；目前 ESP32 V05 仍只會列印固定測試圖／測試券。
- iPhone Safari 不提供通用 Web Bluetooth BLE 存取，不能假設 GitHub Pages 網頁能直接連上 B3S。
- 下一步設備端需新增設定接收、驗證、儲存與列印模板解譯功能。考慮 ESP32 自建 Wi-Fi AP 設定頁供 iPhone Safari 上傳設定，避免依賴 Safari BLE；需另行編譯、實測，完成前不更動 V05。
- 網頁目前沒有真實登入、後端獎券發行、唯一序號、核銷紀錄；不能用作正式抽獎或兌換。
- 核銷須持原店實體紙本正本獎券，照片、截圖、影本、電子圖片不受理。

## 部署
ZIP 中四個檔案放到既有 GitHub `lottery-admin` 儲存庫根目錄覆蓋同名檔案。原本瀏覽器設定會保留，但不同瀏覽器／無痕模式不會自動共用，請先下載完整備份。
