# 電子抽獎機管理平台 v0.1.5（靜態展示版）

## 本版新增
- 獎券模板新增紙張寬度 30／40／50／55／57／58 mm。
- Code 128（一維條碼）與 QR Code（二維碼）版面切換。
- 條碼大小預覽比例、使用規則及注意事項文字大小、顯示開關。
- 蜂鳴器開關、音量偏好與提示音節奏設定（僅本機儲存，尚未控制 ESP32）。
- 保留 v0.1.4 原有獎項管理、獎券欄位及 User 核銷展示介面，沿用 localStorage 鍵 `lottery_ui_v010`。

## 使用方式
ZIP 解壓後將四個檔案 `index.html`、`app.js`、`style.css`、`README.md` 上傳至 GitHub 儲存庫 `a0900067841-bot/lottery-admin` 根目錄，覆蓋同名檔案。或在電腦上直接開啟 `index.html` 先預覽。

## 重要限制
- 網頁條碼為 **示意佔位圖，無法掃描或核銷**；先前 V05 實體 B3S QR Code 測試成功，不代表此版網頁已能直接列印。
- 本版仍為純靜態網頁，沒有登入驗證、後端、真正的唯一券號、庫存扣除、核銷 API、ESP32 設定同步或 B3S 列印控制。
- 實體正本獎券規則不變：照片、截圖、影本及電子圖片一律不受理。
- 實際可列印寬度與不同條碼掃描效果仍需 B3S 實測。
